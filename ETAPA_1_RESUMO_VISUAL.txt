📚 CONCEITOS USADOS:

Templates Django:
   {{ variavel }}              → Exibir variável
   {% lógica %}               → Executar Python
   {% csrf_token %}           → Segurança formulários
   {% extends 'base.html' %}  → Herança de template
   {% block conteudo %}...{% endblock %}  → Área customizável

Formulários Django:
   ModelForm               → Gerar forms de modelos
   forms.CharField()       → Campo de texto
   forms.DecimalField()    → Campo numérico
   forms.EmailField()      → Email com validação
   forms.DateField()       → Data com calendário
   widgets                 → Customizar HTML input
