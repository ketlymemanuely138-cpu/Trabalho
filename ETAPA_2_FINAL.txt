🎯 CONCEITOS DJANGO UTILIZADOS:

  • render() - Renderizar templates
  • get_object_or_404() - Buscar com segurança
  • redirect() - Redirecionar URLs
  • request.POST or None - Form GET/POST
  • form.save(commit=False) - Salvar parcial
  • filter() - Filtrar queryset
  • include() - Incluir URLs de app
  • <int:empresa_id> - Parâmetro URL
  • name='dashboard_loja' - Reverse URL

💡 DICAS IMPORTANTES:

  1. Se erro "Template not found":
     • Execute: python organize_django_templates.py
     • Verifique: APP_DIRS = True em settings

  2. Se erro "Reverse for 'dashboard_loja' not found":
     • Verifique: name='dashboard_loja' em urls.py

  3. Se empresa não vincula corretamente:
     • Adicione print() em views.py para debug

  4. Para testar via shell:
     python manage.py shell
     >>> from core_loja.models import *
     >>> Empresa.objects.all()
